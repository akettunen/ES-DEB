# ES-DEB
Hello & thanks for visiting this repostory. ES-DEB is a [Debian](https://debian.org/) based retro gaming distrobution. This is my (@akettunen) hobby project so don't expect too much from this.

# Install
1. Download .iso on the [releases](https://github.com/akettunen/ES-DEB/releases) page.
2. Make it flashable to an USB stick. (Recommended tools: [Rufus](https://rufus.ie/en/), [BalenaEtcher](https://etcher.balena.io/) of course you can use any tool you want but these are just my beginner friendly recommentations).
3. After flashing the .iso plug your USB stick that has your ES-DEB installation & plug it in to the device you want to install it on.
4. Enter your devices boot menu.
5. Find your USB stick.
6. Install
7. Your all set, thank you for using ES-DEB!

# Basics
Preinstalled: [ES-DE](https://es-de.org) (Launches on startup), [RetroArch](https://www.retroarch.com/), [Kitty](https://sw.kovidgoyal.net/kitty/) & [Firefox](https://www.firefox.com/en-US/)
